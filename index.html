Universality of NOR Gate

A NOR gate alone can synthesize all standard logic operations.

1. INVERTER (NOT)
X = (A + A)' = A'
2. OR Gate
X = ((A + B)')' = A + B
3. AND Gate
X = (A' + B')' = A · B

Universality of NAND Gate

Constructing logic functions using pure NAND architecture.

1. INVERTER (NOT)
X = (A · A)' = A'
2. AND Gate
X = ((A · B)')' = A · B
3. OR Gate
X = (A' · B')' = A + B

Standard & Alternate Gate Symbols

Applying De Morgan's Laws to represent gates with Active-Low logic.

Summary & Circuit Optimization

Universal Gate Advantages

  • IC Cost Reduction: Entire circuits can be fabricated using a single chip type (e.g., 7400 Quad NAND or 7402 Quad NOR).
  • Simplified Inventory: Fewer part numbers required during mass manufacturing.
  • Standardized Propagation Delays: Uniform gate timing across complex logic trees.

De Morgan's Conversion Rules

  • NAND Gate $\equiv$ Inverted-Input OR Gate (Negative-OR).
  • NOR Gate $\equiv$ Inverted-Input AND Gate (Negative-AND).
  • Bubble Matching: Connect output bubbles directly to input bubbles to simplify schematic reading.
